# DJK Opener - Contrôle Parental & Blocage des Réseaux Sociaux

## 📱 Description

DJK Opener est une application Android de contrôle parental qui bloque l'accès aux réseaux sociaux pour améliorer la concentration des étudiants et élèves sur leurs études.

### 🎯 Objectifs
- ✅ Bloquer automatiquement les réseaux sociaux (Facebook, WhatsApp, TikTok, Instagram, etc.)
- ✅ Contrôle parental sécurisé avec mot de passe
- ✅ Persistance du blocage même après désinstallation
- ✅ Interface de déblocage simple via mot de passe
- ✅ Dashboard parent pour la gestion
- ✅ Protection contre la désinstallation

---

## 🚀 Fonctionnalités Principales

### 1. **Blocage des Réseaux Sociaux**
- Détection automatique des apps de réseaux sociaux
- Blocage des tentatives d'ouverture
- Message de restriction personnalisé

### 2. **Déblocage Sécurisé**
- Mot de passe parent : "etienne"
- PIN de déblocage
- Authentification biométrique

### 3. **Persistance**
- Device Administrator pour protection contre désinstallation
- Stockage local des paramètres
- Réactivation automatique après redémarrage

### 4. **Interface Parent**
- Dashboard de gestion
- Statistiques d'utilisation
- Personnalisation des apps bloquées
- Horaires de blocage programmables

---

## ⚙️ Configuration Requise
